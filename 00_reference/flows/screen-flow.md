# 기존 보험 화면 흐름 (AS-IS)

> 캡처 기준. ✅ = 사용자 확인됨 / ❓ = 추정. 02→04→06, 03→05 흐름은 2026-08-17 사용자 확인.

```
[하단 탭바]
├─ 금융 탭 › 보험 (세그먼트)  ····· 화면 01  "내 보험 관리/서비스"
│   ├─ 전문가 상담 배너 → ❓ 상담 화면
│   ├─ 추천 상품 카드 → ❓ 화면 05류 상세
│   ├─ 보장에너지 카드 → ❓ 보장에너지 상세
│   ├─ 건강사전 카드(검색) → ❓ 건강사전
│   └─ 보험 추천 서비스 그리드 (12)
│       ├─ 보험계약조회 → ❓ 내 보험 목록
│       ├─ 보험금청구 → ❓ 청구 흐름
│       ├─ 보험료납입 / 배당금신청 / 중도인출 / 대출신청 / 자동이체 / 분할보험금 → ❓
│       └─ 보장에너지 / 건강사전 / AI영양분석 / 보험거래내역 → ❓
│
└─ 상품 탭 › 보험 (카테고리 탭)  ····· "상품 탐색/가입"
    ├─ [신한은행 세그먼트]  ····· 화면 02
    │   ├─ 필터: 보장 (7)  → 리스트: 상해/암.건강/치매/치아/여행자/대출상환/골프
    │   │     └─ 암.건강 → ✅ 화면 04 (보험상품 목록, 타사 상품 카드)
    │   │           └─ 하나생명 카드 → ✅ 화면 06 (보험상세정보)
    │   │                 ├─ 내 보험료 확인 → ❓
    │   │                 └─ 가입하기 → ❓
    │   └─ 필터: 저축 투자 (3) → 리스트: 변액/노후대비/세액공제  ····· 화면 02-1
    │
    └─ [신한라이프 세그먼트]  ····· 화면 03
        ├─ 카테고리: 암/건강/치아/상해/연금저축 (섹션 점프)
        └─ 상품 아이템 (예: 신한케어받는암보험) → ✅ 화면 05 (상품 상세)
              └─ 보험료 계산하기 → ❓
```

## 메모
- 화면 01의 "추천 상품 카드"(신한케어받는암보험)와 화면 03의 같은 상품이 화면 05로 이어질 것으로 추정.
- 화면 04의 탭(상해/암건강/치매/치아/변액/노후대비)은 화면 02의 보장 7 + 저축투자 3 중 일부만 포함 → 진입 경로에 따라 탭 구성이 달라지는지 확인 필요.
