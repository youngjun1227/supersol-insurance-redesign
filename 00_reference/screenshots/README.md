# 기존 슈퍼쏠 보험 탭 캡처

여기에 기존 슈퍼쏠 앱 **보험 탭** 화면 캡처를 올려주세요.

## 파일명 규칙
`{순번2자리}_{화면이름}.png` 형식 (화면 흐름 순서대로 번호)

예)
- `01_보험홈.png`
- `02_내보험조회.png`
- `03_보험상세.png`
- `04_보험금청구.png`
- `05_보험상품추천.png`

한 화면이 길어서 스크롤 캡처가 여러 장이면 `03_보험상세_a.png`, `03_보험상세_b.png` 처럼 접미사를 붙여주세요.

## 함께 적어두면 좋은 것 (선택)
`../flows/screen-flow.md`에 어떤 화면에서 어떤 버튼을 누르면 어디로 가는지 흐름을 간단히 적어두면 AS-IS 분석이 훨씬 정확해집니다.
