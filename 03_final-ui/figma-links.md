## ⚠️ `clone()` 회귀 목록 — 복제할 때마다 확인할 것

Figma의 `clone()`이 **불투명도·크기 오버라이드를 컴포넌트 기본값으로 되돌리는** 사례가 반복해서 나왔다. 화면·페이지를 복제하면 아래 3가지를 **매번** 다시 확인한다.

| # | 되돌아가는 것 | 증상 | 정상값 |
|---|---|---|---|
| 1 | 팝업 인스턴스 **딤 fill opacity** | 뒤 배경이 새까맣게 덮임 | **0.40** (2026-08-24 55%→40% 조정) |
| 2 | **중첩 인스턴스 크기** (신한 심볼 등) | 아이콘이 커짐 (24 → 32×35) | 24×24 |
| 3 | **반투명 fill opacity** | 잠금화면 알림 카드가 흰 판이 되어 흰 글자가 사라짐 | 카드 **0.10** (`bg` 변수 바인딩 유지) |

점검 스크립트 예:
```js
// 딤
for (const n of root.findAllWithCriteria({types:['INSTANCE']})) {
  const mc = await n.getMainComponentAsync();
  if (mc?.parent?.id === '52:88' && n.fills[0]?.opacity !== 0.40) { /* 고치기 */ }
}
// 반투명 fill — 원본에서 <1인 fill을 경로로 기록해두고 비교
```
