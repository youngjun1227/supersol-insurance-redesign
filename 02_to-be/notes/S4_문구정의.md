> 근거: `docs/디자인브리프_v2_2026-08-17_팀-아이디어-4개.md` §2 아이디어 3 · §3 / 값은 `02_to-be/mock-data.md` §5.

## 0. 흐름 (2026-08-17 팀장 확정)

```
① 신한카드 병원 결제 발생
        ↓
② **앱 푸시 알림** (기본)  잠금화면 S5-C / 상단 배너 S5-D — 같은 알림의 두 모습
   ↘ 앱 알림을 껐거나 설정에서 카톡을 고른 경우 → ②' 카톡 알림톡 S5-B
        ↓ (알림을 누르거나 · 그냥 쏠에 들어가거나)
③ 앱 진입 팝업  결제 건 + 필요 서류 3줄 + [보험금 청구하기]      ← S4-A
        ↓  (기존 랜딩 07-1 · 시작시트 07-2를 건너뜀)
④ 청구 절차 안내  절차 4단계 + 준비 서류 + [청구 시작하기]        ← S4-D
        ↓
⑤ AS-IS 07-3 "1/5 신청대상 선택" (청구 1/5~5/5는 재설계 안 함)
```

⑤가 도착지인 이유: **보험금 청구를 누르면 원래 가장 먼저 뜨는 화면**이 1/5 신청대상 선택이다.

**계정 상태 전제:** 이 흐름 전체는 **상태 B(신한라이프 보험 2건)**를 전제로 한다. 청구 알림은 신한라이프 보험이 있는 사람이 대상이기 때문이다. 캡처된 07-3은 계정에 신한라이프 보험이 없어 빈 상태였고, 도착지 화면은 그 구조에 상태 B를 넣어 재구성했다 — **실제 '보장대상 있음' 화면은 미캡처**이므로 8/25 전에 캡처해서 맞출 것.

**팝업이 안 뜨는 사람**(현금 결제 · 타사 카드 · 며칠 지난 진료)은 **기존 방식 그대로** 청구한다 — 보험 메인 → 07-1 랜딩 → 07-2 시작시트 → 1/5. 우리가 대체 화면을 만들지 않는다(§5).

**S4-A의 디자인 근거:** AS-IS 07-2 시작 확인 시트의 시트 구조(X 닫기 · 중앙 일러스트 · 중앙 제목 · 회색 인포 박스 · 풀버튼)를 **그대로 쓰고 내용만 우리 것으로 바꿨다.** 같은 시트를 쓰므로 학습 비용이 없고, 시작시트가 하던 "제출서류를 준비하셨나요?" 역할을 팝업이 흡수하므로 시트를 중복으로 둘 이유가 사라진다.

**카드의 역할은 "병원에 갔다"는 감지까지.** 결제 건을 골라서 청구하는 방식(모니모형)은 채택하지 않는다 — 브리프 §2의 "결제 내역 선택 방식"과 갈리는 지점이므로 8/25에 보고할 것.

### 결제 내역 선택 방식을 뺀 이유 (8/25 보고용)
1. 카드 내역이 대신하는 건 **정보 입력**(병원명·진료일·금액)뿐이고, **서류 제출은 그대로 남는다.** 영수증을 올리면 거기서 같은 값을 읽으므로 중복이다.
2. **카드 결제액 ≠ 청구 대상 금액**일 가능성이 있다 — 비급여 별도 계산, 일부 현금, 약국 별도 결제. 미리 채운 값이 영수증과 어긋나면 고치게 만들거나 틀린 채로 제출될 수 있다.
3. 모니모가 결제 내역 목록을 쓰는 목적은 "고르게 하는 것"이 아니라 **"아직 청구 안 한 건이 N건"을 보여주는 것**으로 보인다. 그 역할은 우리 흐름에서 알림·팝업이 한다.
4. 남는 값 하나 — 여러 건이 밀렸을 때의 **미청구 건 모아보기**. 이건 S1 현황 카드 쪽 논의로 넘긴다(지금 S4 범위 밖).

| 화면 | 상태 |
|---|---|
| S4-A 앱 진입 팝업 | 그림 (핵심) |
| S4-B 위치 기반 변형 | **폐지** (2026-08-17) — 아래 §1-B. 그린 화면은 보류 섹션에 둠 |
| S4-C 청구 랜딩 안① | **보류** (2026-08-17) — 브리프 근거 없음(범위 밖). 아래 §5 |

| S4-E 청구 갈래 | **보류** — 갈래를 나눌 이유가 없어짐 |

## 1. 앱 진입 팝업

### S4-A — 1안 카드 결제 감지 (기본)
| 요소 | 문구 |
|---|---|
| 제목 | **이 진료비, 보험금 청구할 수 있어요** |
| 본문 | 8월 17일 ○○내과의원 32,000원 결제 |
| 서류 안내 라벨 | 청구하려면 이 서류가 필요해요 |
| 서류 1 | 진료비 계산서·영수증 |
| 서류 2 | 진료비 세부내역서 |
| ~~서류 3~~ | ~~진단서~~ — **팝업에서는 뺀다** (2026-08-18) |

**팝업에 진단서를 넣지 않는 이유:** 이 팝업은 **특정 결제 건(32,000원 통원)에 대한 안내**다. 진단서는 금액이 크거나 입원한 경우에만 필요하므로 이 건에는 해당이 없다. 조건부 서류 안내는 절차 안내(S4-D)가 맡는다. 팝업이 짧아지는 것은 부수 효과이고, **맞지 않는 정보를 빼는 것이 본래 이유**다.
| 버튼 1 (주) | 보험금 청구하러 가기 |
| 버튼 2 | 나중에 하기 |
| 버튼 3 (텍스트) | 이 알림 받지 않기 |

- 날짜·가맹점·금액은 mock-data §5 첫 행 고정.
- **서류 3줄을 팝업 안에서 끝낸다.** "병원을 나오기 전에 뭐가 필요한지 안다"가 이 아이디어의 핵심이라 한 번 더 누르게 하지 않는다.
- 버튼 1 → **기존 보험금 청구 페이지**로 이동(우리가 그리지 않음).
- 버튼 3 → S5-A(알림 설정). 팝업 안에서 바로 끄지 않고 **끄는 방법이 어디 있는지 보여주는** 경로로 둔다.

### S4-B — 2안 위치 기반 → **폐지 (2026-08-17, 팀장)**

**사유:** 도심 건물에는 **한 건물에 병원이 여러 곳** 있는 경우가 많다. 위치만으로는 어느 병원·어느 과를 갔는지 가릴 수 없고, 애초에 병원에 간 것이 맞는지도 확정할 수 없다(문병·인접 상가 방문 등). 오탐이 잦은 알림은 켜 둘 이유가 없어진다.

**남는 영향:** 1안(카드 결제 감지)의 **대체안이 사라졌다.** 1안이 규제로 막히면 아이디어 3 자체가 흔들린다 → **S5-A 알림 동의(opt-in) 화면이 1안을 살리는 유일한 경로**라 중요도가 올라간다. 8/25 멘토 질의에서 1안의 규제 판단을 우선순위로 둘 것.

그린 화면은 규칙대로 지우지 않고 보류 섹션(`53:311`)에 뒀다. 아래는 폐지 전 문구(기록용).

| 요소 | 문구 |
|---|---|
| 제목 | ~~병원에 다녀오셨나요?~~ |
| 본문 | ~~진료비 영수증과 세부내역서를 챙기면 보험금을 청구할 수 있어요.~~ |

### 문구 강도 기준 (2026-08-17 재정리)

**"청구하세요"까지는 쓸 수 있다.** 막히는 것은 **신규 가입 권유**(보험 모집)이지, 기존 계약의 보험금을 청구하라고 알리는 것은 계약 유지·관리에 해당한다. 계열사 결제 정보 사용은 S5-A의 opt-in 동의로 해결된다.

**넘지 않는 선 — "보험금 받을 수 있어요"는 쓰지 않는다.**
규제 때문이 아니라 **사실이 아닐 수 있어서**다. 32,000원 진료비면 자기부담금·면책으로 실제 지급이 적거나 0일 수 있다. 지급을 단정하면 민원이 된다. **"청구할 수 있어요"까지.**

| | |
|---|---|
| ❌ | "보험금 받을 수 있어요" · "숨은 보험금" · "놓치고 계신 보험금" — 지급을 단정 |
| ❌ | "이 참에 보험 하나 더 준비하세요" — 신규 가입 권유 |
| ✅ | "이 진료비, 보험금 청구할 수 있어요" — 권리 안내 |
| ✅ | "병원 나오기 전에 영수증·세부내역서를 받으세요" — 행동 안내 |

**문구 순서 원칙:** 얻는 것(청구할 수 있다) → 어떤 건(진료 건) → 지금 할 행동(서류 받기).
~~"병원 결제 내역이 있어요"~~는 쓰지 않는다 — 사용자가 방금 자기가 결제한 사실이라 새 정보가 아니다.

## 5. 청구 랜딩은 손대지 않는다 (2026-08-17 확정)

**기존 청구 랜딩(07-1)과 청구 화면(1/5~5/5)은 그대로 둔다.** 팝업이 안 뜨는 사람은 지금 방식으로 청구하면 된다.

이유:
- 브리프 어디에도 "청구 랜딩을 고친다"는 항목이 없다. 아이디어 3의 '그릴 것'은 ① 카톡 알림 ② 앱 진입 팝업 ③ 절차 미리 안내 ④ 동의 화면뿐이다.
- §3 "청구가 보험추천서비스 하위에 숨음"의 흡수처는 **"보험 메인에서 청구를 무스크롤 위치로"** — 그건 S1-1의 2분할 버튼 `[보험 찾기 | 보험금 청구]`가 맡는다.
- "카드는 감지까지, 청구는 기존 방식"이라는 §0 결정과 어긋난다.

**커버하지 않는 범위(인정하고 남겨둠):** 팝업이 안 뜨는 경우 — 현금 결제 · 타사 카드 · 며칠 지난 진료 — 에는 R-11(필요 서류가 어느 화면에도 안 보임)이 그대로 남는다. 아이디어 3이 못 덮는 구간으로 두고 8/25에 팀이 판단한다. 시안을 늘려서 미리 메우지 않는다.
