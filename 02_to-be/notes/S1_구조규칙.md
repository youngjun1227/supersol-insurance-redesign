## 0. 이 화면이 풀려는 것

**AS-IS는 누구에게나 같은 12개를 보여준다.** 그런데 서비스 12개를 계약 유무로 나누면 이렇다.

| | 서비스 | 개수 |
|---|---|---|
| **계약이 있어야 쓸 수 있음** | 보험계약조회 · 보험거래내역 · 보험금청구 · 보험료납입 · 보험계약대출신청 · 배당금신청 · 자동이체등록/변경 · 중도인출신청 · 분할보험금신청 | **9** |
| 계약 없어도 쓸 수 있음 | 건강사전 · AI영양분석 · 보장에너지 | 3 |

→ **가설: 보유 0건 20대에게는 12개 중 9개가 눌러도 빈 화면일 가능성이 있다.** 아이디어 2(연령·보유상품 맞춤)가 실제로 바꾸는 것은 "상단에 카드 한 장 얹는 것"이 아니라 **누구에게 무엇을 어떤 순서로 보이느냐**다.

## 2. 상태별 순서 규칙

### 보유 0건 20대 (두 번째 상태 — 2026-08-18 기본값이 B로 바뀜)
```
① 맞춤 영역        소액 첫 보험 1~2장
② 현황 카드        "가입한 보험이 없어요 · 이번 달 0원"
③ 핵심 행동        [보장 진단 | 보험 찾기]      ← 청구가 아니라 진단
④ 지금 쓸 수 있는 것  건강사전 · AI영양분석 · 보장에너지
⑤ 접힘            "가입하면 쓸 수 있어요 (9)"
⑥ 보장에너지 카드
⑦ 배너            상담 · 이벤트
```

### 보유 1~2건 20대 (**기본 상태** — 설문 Q3·Q4: 20대 다수가 가족이 들어준 보험 있음)
```
① 맞춤 영역        "가족이 들어준 보험 한눈에"
② 현황 카드        "보험 2건 · 이번 달 35,000원"    ← 과제 '이번 달 보험료 확인' 정답값
③ 핵심 행동        [내 보험 | 보험금 청구]
④ 조회·계약        보험계약조회 · 보험거래내역 · 자동이체등록/변경
⑤ 청구·신청        보험금청구 · 보험료납입 · 보험계약대출신청 · 배당금신청 · 중도인출신청 · 분할보험금신청
⑥ 정보            건강사전 · AI영양분석
⑦ 보장에너지 카드
⑧ 배너
```

**③ 핵심 행동 2분할의 라벨이 상태에 따라 달라지는 것이 이 아이디어의 가장 눈에 보이는 변화다.** 0건에게 [보험금 청구]는 누를 이유가 없다.

> **안② 급진에서의 변형 (2026-08-18 확정)** — 위 순서는 **안① 보수의 기준**이다. 안②는 구성 자체를 바꾸므로 다음처럼 벌어졌다. 이 차이가 곧 "정도의 차이"이고, 8/25에 팀이 고르는 대상이다.
>
> | | 안① 보수 (찬영) | 안② 급진 (영준) |
> |---|---|---|
> | 0건 최상단 | 맞춤 카드 + 현황 카드 | **온보딩 헤드라인** ("아직 준비된 보험이 없어요") — 현황 카드 없음 |

## 3. 못 쓰는 메뉴 처리 — **접기** (택 (가))

0건 화면에서 계약이 필요한 9개는 **"가입하면 쓸 수 있어요 (9)"** 한 줄로 접는다.

- 아예 안 보이게 하지 않는다 → "숨긴다"는 인상을 준다
- 흐리게 + 가입 유도도 하지 않는다 → 광고로 읽힌다
- 접힌 줄을 누르면 펼쳐진다. **경로를 막지 않는다.**

문구: `가입하면 쓸 수 있어요 (9)` — 개수를 적어 무엇이 얼마나 있는지 알린다.

## 5. "왜 이것이 보이는지" + 끄기 — **4장 전부 필수**

맞춤 영역 바로 아래 **한 줄** + S1-13 시트 진입. **이 한 줄의 오른쪽 링크가 시트로 가는 유일한 입구다** (별도 진입 버튼 없음).

- 문구 (2026-08-18 확정 / **링크만 2026-08-24 변경**): `가입 보험 0건 · 20대 기준으로 보여드려요` / `가입 보험 2건 · 20대 기준으로 보여드려요` + `맞춤 설정 >`
  - ~~`기준 바꾸기 >`~~ → ~~`왜 보이나요 >`~~ → **`맞춤 설정 >`** (2026-08-24 두 번 고침)
    - `기준 바꾸기` 폐기: 나이·보유 계약은 회원정보/보험계약조회에서 오는 **사실**이라 사용자가 바꿀 수 없다
    - `왜 보이나요` 폐기: ① 왼쪽 문장이 이미 "…기준으로 보여드려요"라고 답했는데 오른쪽에서 다시 묻는다 ② 누가 묻는 말인지 모호하다 ③ 시트가 하는 일의 절반(근거 공개)만 가리키고 **끄기**를 예고하지 못한다
    - `맞춤 설정` 채택: 시트가 하는 일 둘(근거 공개 + 맞춤 끄기)을 다 포괄하고, 질문이 아니라 동작이라 링크답다. 폭 63 → 51px (여유)
  - **보유 기준을 앞에** — 설문 Q7에서 '가입 보험 기준' 52.5% > '나이 기준' 28.7%. 사람들이 더 원한 축을 먼저 말한다
- ~~"20대이고 가입한 보험이 없어서 이 순서로 보여드려요"~~ — 두 줄로 꺾여서 폐기
- 근거: 선별 기준 공개 요구 **69.8%**, 20대 **36.1%**가 개인화 이용 망설임(KISDI 2025), 마이데이터 저해 1위 "자사 중심 추천"(하나금융 2022)
- **빠지면 이 아이디어는 "맘대로 골라 보여주는 화면"이 된다.** 설문 Q12에 "골라 보여주는 것 자체가 별로"라는 선택지가 있다.

### S1-13 시트가 하는 일 (2026-08-24 재설계)

| | 내용 |
|---|---|
| 제목 | `보여드리는 기준` |
| 본문 | `20대 · 가입 보험 0건 기준으로 화면 순서를 구성했어요` |
| **읽기 전용 2행** | `연령대 — 20대 · 회원 정보` / `보유 계약 — 0건 · 보험계약조회` — **출처를 함께 적는다.** 사용자가 못 바꾸는 값이라 체크박스가 아니라 키-값 행 |
| **토글 1개** | `맞춤 구성 사용` + `끄면 모두에게 같은 화면으로 보여드려요`. 여기만 **행동**이다 |
| 버튼 | `확인` 하나 (X 닫기는 유지 — 적용 없이 닫기) |

**전 설계에서 고친 것** — 체크박스 3개가 사실(연령대·보유계약)과 행동(맞춤 끄기)을 같은 컨트롤로 섞어 놨고, 적용 중인데 셋 다 꺼져 있었으며, `이대로 볼게요`+`닫기` 두 버튼이 같은 동작이었다.
**테마 전환 기능은 넣지 않는다** — 사용자가 자기 나이를 바꿔 다른 테마를 볼 이유가 없다 (S1_맞춤테마체계 §규칙에서도 삭제).
