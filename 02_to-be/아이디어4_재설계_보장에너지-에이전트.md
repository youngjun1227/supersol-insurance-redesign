## 1. 왜 재설계하나 — 앱이 업데이트됐다

8/24 실기기 확인: **보장에너지 신버전**이 우리가 그리려던 걸 이미 한다.
캡처 9장: `00_reference/screenshots/01_금융-보험홈_d_*` + `08_*` 시리즈 (실명 모자이크 처리됨 — **발표·시안 이미지에 캡처 직접 사용 금지**).

실물 신버전이 이미 제공하는 것:
- 또래 비교 수치 ("20대 남성" 게이지), Total %, 항목별 배터리(색=수준)
- 항목별 보장금액 + 연령별 막대
- **보유 계약 매칭** ("이 보험에서 보장해요" — 부모 가입 타사 보험까지 잡음)
- **"대화로 쉽게 물어보기" = 실제 LLM 에이전트** (키워드 챗봇 아님 — 문장을 이해하고 답변하는 것 실사용 확인)

→ 기존 가설("수치로 보여주면 좋을 것이다")은 실물이 구현했다. **가설 업데이트: "수치는 이미 있다. 필요한 건 이해 지원이다."**

상세 화면의 **정보 설계 자체는 충실하다** — 크게 다시 그릴 이유가 없다.
비어 있는 건 두 가지: ① 처음 온 사람이 읽기 전에 이해하게 해주는 **입구**, ② 보다가 막힌 순간의 **출구**.

## 3. 방향 — 실물의 LLM 에이전트를 전면으로

우리가 지어낸 기능이 아니라 **실물에 이미 있는 에이전트**를 UX의 중심으로 옮기는 제안.

### 마찰 → 대응 (전부 리서치 근거 연결)

| 마찰 | 근거 | 대응 |
|---|---|---|
| 첫 진입자가 데이터 화면을 해석 못 함 | Q2 약 70% 앱 비사용 · Q4 약 72% 가족 보험 내용 모름 | **S3-D 브리핑 화면** — 에이전트가 말로 요약 |
| 보다가 용어·수치에 막혀도 물어볼 곳 없음 | Q11 자유응답 "조금만 알아보려 하면 바로 전화상담으로 넘어가서 부담" · R-21 | **문맥 질문 💬** — 항목 옆에서 바로 질문 |
| 경고 화법의 부담 | Q9 "부담스럽다" 7.5% · R-18 | 에이전트 톤 = 사실 서술 + 비권유 |
| 수치 근거 불투명 | KISDI 기준 공개 요구 69.8% | "왜 이 수치인가요" 시트 (제작 완료) |

### ⚠️ 챗봇 함정 — 반드시 지킬 것
챗이 정보를 **대체**하면 UX 악화다(정보를 대화 뒤에 숨기는 꼴). 원칙: **상세 정보는 화면에 그대로, 질문은 보조 수단.** 채팅으로만 알 수 있는 정보를 만들지 않는다.

## 4. 화면 구성 3장

### S3-D 첫 화면 (신규) — 진입 시 이걸 먼저 만난다
```
[신한 심볼 아바타] 보장 상담 에이전트
💬 "김신한님의 보장을 확인했어요. 16개 항목 중 2개가 준비돼 있어요."  (+Total 포션 소형)
💬 "20대는 실손의료비·입원부터 보면 돼요. 가입을 권하는 건 아니에요."
궁금한 걸 바로 물어보세요
  「부모님이 들어준 보험도 포함돼 있나요?」   ← 질문 칩은 키워드가 아니라 자연어 문장
  「실손의료비가 뭐예요?」
[자세한 진단 보기] → S3-C
```
- **캐릭터 금기**: 마스코트(곰) 재현 금지 + 캡처 추출 금지 → 아바타는 **신한 원형 심볼**(`로고 (신한)` `360:7488`). 발표에서 "실서비스는 공식 캐릭터로"라고 말로 처리.
- 질문 칩이 문장인 이유: 문장을 이해하는 LLM임을 화면이 스스로 보여준다. 첫 칩은 Q4 직결.

### S3-C 상세 (기존 v3 유지 + 💬 추가)
- 이미 제작됨: 포션 대시보드(스캔 행) → 먼저 볼 항목 카드 2 → 그 밖의 항목 리스트 → 내 보험 매칭 → 비권유 푸터
- 추가할 것: **항목 행마다 💬 아이콘** (Phosphor `상담` 재사용) — "보다가 그 자리에서 질문"
- 항목 분류는 **16개로 정정 예정** (기존 5개는 구버전 기준의 우리 분류라 실물과 안 맞음 — 나머지 6개 항목명 확보 대기 중). 16개는 나열하지 않고 성격별 4그룹으로 묶는다 (치료비 / 큰 병 / 노후·간병 / 만일) — R-19에 대한 구조적 답
- 실측 기반 톤 수정치는 유지: 딤 40%, h1 22 등

### 답변 시트 (신규) — LLM 시연 1왕복
사망 항목 💬 탭 →
> **Q** "사망 보장은 꼭 필요해요?"
> **A** "부양가족이 없는 20대 1인 가구라면 서두르지 않아도 되는 항목이에요. …가입을 권하는 건 아니에요."

**핵심 대비**: 실물은 같은 항목에서 "보장이 텅 비었어요!"(주황 경고). 같은 데이터 — 한쪽은 겁을 주고, 한쪽은 판단을 돕는다. 시연에서 가장 선명한 장면.

## 10. 우선순위 티어 구조 — S3-C 최종 (2026-08-25, 팀장 방향)
"또래 대비 N%"는 실물도 하는 것 — **연령 기준 우선순위 판단**이 진짜 차별점이라는 팀장 지적으로 항목 층을 성격별 그룹 → **우선순위 4티어**로 교체:

| 티어 | 항목 | 표현 |
|---|---|---|
| **지금 채우면 좋아요** (파란 강조 바) | 실손의료비 · 입원 | 풀카드 + 이유("병원비 부담이 가장 잦은 보장인데 아직 없어요") |
| 여유 있을 때 봐도 돼요 | 수술·치과·심혈관·뇌혈관·치매·후유장해 (6) | 슬림 |
| 이미 준비돼 있어요 | 암 진단 | 슬림 (0건 상태에선 티어 자체가 사라지고 암은 '여유'로) |
| 지금은 서두르지 않아도 돼요 | 사망 | 슬림 + 이유("보통 부양가족이 생길 때 필요해져요") + 💬 |

- 헤더에 "20대 기준 우선순위로 정리했어요" 명시 — 판단 기준 공개(KISDI 69.8%)
- 실물과의 최종 대비: **실물 = 전 항목을 부족하다고 경고 / 우리 = 지금 볼 것과 아닌 것을 갈라줌**
- ⚠️ 표현 규칙 경계: "채우면 좋아요"는 권유에 가까움 — 이유(사실)와 "가입을 권하는 건 아니에요" 푸터를 반드시 유지. 8/25에 이 경계 자체를 논의 안건으로
