## 2. 타사·병원 표기 방침 — 위 문서에 한 줄
**실명("하나생명", "○○내과") vs 가명("A생명", "○○병원")** 중 택1. 나중에 바꾸면 전 화면 수정이라 지금 정할 것.
→ 권장: 시안은 **가명**(A생명·B생명 / ○○병원). AS-IS 캡처엔 실명이 있으니 대비도 됨.

## 5. Figma `시안` 페이지를 S1~S6 구조로 재구성
지금은 T1~T4 [H-###] 임시 구조. 아래로 바꿀 것.

```
⚠️ 시안 규칙 배너
📋 템플릿 A / B / C
S1 보험 메인 [아이디어 2 + §3]      ← 영준 뼈대 슬롯 + B 맞춤 슬롯
S2 상품 찾기 목록 [아이디어 1]        ← A
S3 보장 진단 결과 [아이디어 4]        ← B
S4 청구 알림 → 보험금 청구 [아이디어 3] ← 영준
S5 알림 동의 · 카톡 [아이디어 3]      ← 영준
S6 상품 상세 [§3]                   ← A
🗂 보류
```
각 섹션에 **안 슬롯(빈 프레임) + AS-IS 대응 화면 자리 + 노트 템플릿**을 미리 깔아둘 것. 팀원은 템플릿 복제해서 슬롯에 넣기만 하면 됨.
