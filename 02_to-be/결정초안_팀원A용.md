# 팀원 A에게 주는 결정 초안 5개

> A가 판단하기 어려운 것들. **이대로 반영**하면 되고, 그리다가 이상하면 영준에게 말할 것.
> (영준: 아래는 제안값이니 확인 후 확정 표시할 것)

## S2-8. 판매사 표기 기준
**→ 제조 보험사명만 표기. 채널명은 필터/뱃지 라벨에서만.**
- 상품 줄에는 `A생명` `신한라이프` 처럼 **만든 회사**를 적는다
- "신한은행"은 상품을 만든 회사가 아니라 파는 곳이므로 상품 줄에 쓰지 않는다
- 필터 칩 라벨은 `신한은행에서 파는 상품` / `신한라이프 상품` 처럼 채널 기준
- 이유: 지금은 은행 탭엔 회사명이 없고 라이프 탭엔 줄마다 붙어 있어 반대로 돼 있음(O-304)

## S2-9. 회사 필터 칩 기본 상태·순서
**→ 기본 "전체" 선택. 순서 [전체] [신한은행] [신한라이프].**
- 기본이 한쪽이면 지금(기본=신한은행)과 같은 문제가 남음
- 순서는 AS-IS와 동일하게 은행 먼저 (순서 변경 가능 여부는 멘토 확인 대상이라 현행 유지)

## S2-10. 카테고리 탭 동작
**→ 같은 화면에서 필터 전환 + 스크롤 시 상단 고정(스티키).**
- 다른 화면으로 이동하지 않는다 (클릭 수가 늘어남)
- 지금은 스크롤하면 아이콘 그리드가 칩으로 모양이 바뀌는데, **처음부터 칩 하나로 통일**해서 형태가 안 바뀌게

## S2-13. S2 화면 상위 내비 포함 범위
**→ 헤더(모든상품 ▾) + 상품 카테고리 탭 7개를 그대로 얹고 시작.**
- 우리가 바꾸는 건 그 아래(회사 탭 → 카테고리)이므로, 위는 AS-IS 그대로 둬야 비교가 공정
- 단 화면이 길어지니 노트에 "상단 2단은 AS-IS 유지" 한 줄 적어둘 것

## S6-2. 자사/타사 상품 상세 통일 방향
**→ AS-IS 06(타사 상세) 쪽 구조로 통일.**
- 구조: 회사 로고 → 상품명 → 요약 스탯 3개(납입방법·가입나이·보험기간) → 버튼 → 탭(상품안내/보장내용/유의사항)
- 이유: 스펙이 첫 화면에 보이고, SOL 본체 스타일(버튼 h48·r8)이라 앱 전체와 일관됨
- 05(자사)의 좋은 점인 **하단 고정 CTA**는 가져와도 됨
- 버튼 2개가 둘 다 Primary인 문제는 **하나를 보조 버튼으로** 낮출 것
