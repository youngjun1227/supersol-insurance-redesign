## 그릴 화면

### S2-A — 카테고리 탭 상단 + 회사 필터 칩
- 위: 보장 카테고리 탭 (보장 / 저축투자 → 암·건강·치아·상해…)
- 그 아래: [전체][신한은행][신한라이프] 필터 칩
- 목록: 두 회사 상품이 섞여 나옴, 각 줄에 판매사 표기
- 카테고리 아래 어딘가에 구분 기준 한 줄 설명

### S2-B — 카테고리 상단 + 판매사 뱃지 (회사 탭 없음)
- 회사 구분 UI를 아예 없앰
- 대신 상품 카드마다 판매사 뱃지
- 제일 단순한 안

### S2-C — 상황 문장 카테고리
- 카테고리 이름을 "암·건강·치아" 대신 **"내 건강 챙기기" / "가족을 위해서" / "노후 준비"** 같은 문장으로
- 그 아래는 A안과 비슷하게

### S2-D — 카테고리 선택 후 목록 화면 1장
- 위 안 중 하나를 골라, 카테고리를 눌렀을 때 나오는 목록

### S6 — 상품 상세 1장
- AS-IS 05(자사)/06(타사) 중 영준이 정해준 방향으로 통일
- 용어 옆에 툴팁 1~2개 붙이기

## 같이 만들 문서 (Figma 옆 노트 또는 md)
- **S2-5 통일 카테고리 체계** — 지금 은행 탭 7~8개 + 라이프 탭 5개를 어떻게 하나로 합칠지. 겹치는 이름(암·건강·치아·상해)은 하나로, 한쪽에만 있는 것(여행자·대출상환·골프 / 연금저축)은 어디에 넣을지
- **S2-6 상황 문장 목록** (C안용) — 문장 5~6개와 각 문장에 들어갈 상품
- **S2-7 구분 기준 설명 문구** 2~3개 후보 — 예: "은행에서 파는 다른 보험사 상품 / 신한라이프가 직접 만든 상품"
- **S2-11 상품 카드에 무엇을 쓸지** — 회사명·상품명·설명 길이 통일 + 월 보험료 예시나 핵심 보장 한 줄을 넣을지 (지금은 비교할 정보가 없음)
- **S2-12 툴팁 대상 용어** 1~2개 (예: 무배당, 갱신형, 해약환급금)
- **S2-14 목록 안 부가 요소** — 지금 목록에 끼어 있는 추천 캐러셀 / 비과세·맞는보험찾기 카드 / 중간 보장에너지 배너 / 이벤트 배너를 유지할지 내릴지 뺄지

## 안마다 옆에 노트 (필수)
```
기대는 아이디어: 1
참고한 앱 화면: 모니모 상품 분류 / 토스 상황별 분류
바꾼 것: 
기대 효과(사용자 관점): ~할 가능성이 있다
```
- "사용자는 불편해한다" 같은 단정 금지 → "가설: ~", "~할 가능성"
- "신한라이프 노출이 늘어난다" 같은 회사 관점 금지 → "찾는 상품에 더 빨리 닿는다"

## 하면 안 되는 것
- 잠긴 원본 컴포넌트 섹션 수정, Detach instance
- 변수·텍스트 스타일 새로 만들기 (컴포넌트는 규칙대로 만들어도 됨 → `🆕 신규` 섹션에)
- 색 입히기 (지금은 회색조)
- "개선안"이라는 단어 쓰기 (지금은 전부 "시안")
