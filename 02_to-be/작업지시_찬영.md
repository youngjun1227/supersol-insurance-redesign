# 파트 1. S3 보장 진단 결과 (아이디어 4) ← 먼저

## 무엇을 바꾸는 것인가
지금 보장에너지는 **"보장금액이 하나도 없어요" + "전문가에게 물어보세요"** 가 전부다. 뭐가 얼마나 부족한지, 뭐랑 비교한 건지 없다.
가설: 판단할 근거가 없고, 정보를 보러 온 사람에게 가입 권유로 읽혀 나갈 가능성.
**주의: "가입을 더 하게 만드는" 방향이 아니다. 정보를 주는 방향으로만 그린다.**

## 그릴 화면 (4장)
| 프레임 | 내용 |
|---|---|
| S3-A / 보유 0건 | 수치 목록형 — 항목(암·입원·실손·상해·사망)별로 [내 보장금액 / 또래 평균 / 부족·충분 뱃지] 를 세로 리스트로 |
| S3-A / 보유 1~2건 | 같은 구조, 수치가 실제로 있는 버전 |
| S3-B / 보유 0건 | 그래프형 — 위에 오각형 그래프 1개 + 아래 부족 항목 뱃지들 + 항목 상세 |
| S3-B / 보유 1~2건 | 같은 구조, 수치 있는 버전 |

> 상태 2개는 **같은 프레임을 복제해서 숫자만 바꾸면** 됨.

## 두 안 모두에 반드시 들어갈 4가지
1. **항목별 수치** (금액)
2. **비교 기준 문장** — "20대 중반과 비교했어요"
3. **한계 문구** — "보험마다 기준이 달라 실제와 다를 수 있어요"
4. **상담·가입 버튼은 맨 아래** + "가입을 권하는 것이 아닙니다" 한 줄

## 같이 만들 것
- **S3-4** "보장금액이 하나도 없어요" 대안 문구 2~3개 (0건일 때 뭐라고 쓸지)
- **S3-6** 진단 항목·수치 목데이터 — 항목 5~6개, 또래 평균 금액 (영준의 목데이터 문서에 추가)

# 파트 2. S1 맞춤 영역 (아이디어 2) ← 영준 뼈대 나온 뒤

## 무엇을 바꾸는 것인가
지금 보험 화면은 누구에게나 똑같다. 연령·보유 상품에 따라 **맨 위에 맞는 것부터** 보여준다.
가설: 20대는 보험을 잘 몰라 판단이 어렵고, 부모가 들어준 보험이 뭔지 모를 가능성.

## 그릴 화면 (4장 + 2)
| 프레임 | 내용 |
|---|---|
| S1맞춤-A / 0건 | 영준의 S1 뼈대 **맨 위 슬롯**에 맞춤 카드 1~2장, 아래는 공통 그대로 |
| S1맞춤-A / 1~2건 | 같은 구조, 가입 보험이 있는 버전 |
| S1맞춤-B / 0건 | 화면 전체가 상태에 따라 다른 구성 (토스식) |
| S1맞춤-B / 1~2건 | 같은 구조 |
| S1-13 | "기준 바꾸기 / 끄기" 눌렀을 때 바텀시트 1장 |
| S1-14 | "가족이 들어준 보험 한눈에" 카드 — 보험 목록 + 보장 요약 |

## 전 안에 반드시 들어갈 것 (S1-12)
- **"왜 이것이 보이나요?" 한 줄** — 예: "26세 · 가입 보험 0건 기준으로 골랐어요"
- **기준 바꾸기 / 끄기** 진입 (작은 링크나 아이콘)
→ 개인화에 대한 거부감·데이터 우려 때문에 이게 없으면 안 됨

## 같이 만들 것
- **S1-15 맞춤 테마 체계 문서** — 테마 5~6개(20대·30대…) 각각의 이름, 어떤 기준으로 판정하는지, 무슨 카드를 보여주는지. **MVP에 그리는 건 20대 2상태뿐**이지만 체계는 정리해둬야 노트에 "왜 이게 보이는지"를 쓸 수 있음
- **S1-16** 보장에너지 진입 카드 갱신 (S1에서 눌러 S3로 가게)

## 안마다 옆에 노트 (필수)
```

참고한 앱 화면: 토스 진단 리포트 / 모니모 진단
바꾼 것: 
기대 효과(사용자 관점): ~할 가능성이 있다
```
