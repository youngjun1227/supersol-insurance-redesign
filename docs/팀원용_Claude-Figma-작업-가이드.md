# 팀원용 — Claude + Figma MCP로 작업할 때 가이드

> 대상: 슈퍼SOL 보험 리디자인 팀원 (Claude Max + Figma 커넥터 사용)
> Figma 파일: https://www.figma.com/design/4ZvrCenVFT98F0VMIYaAp4/
> 마지막 갱신: 2026-08-17

## 0. 먼저 한 번만
1. claude.ai → 설정 → 커넥터 → **Figma** 연결 (Figma 계정 로그인)
2. Figma 파일 열어서 첫 페이지 **📖 시작하기** 한 번 읽기 (5분)
3. 이 문서의 "시작 프롬프트"를 메모장에 저장해두기 — 매번 붙여넣을 것

## 1. 역할 분담 (중요)
| 누가 | 하는 것 | 안 하는 것 |
|---|---|---|
| **영준** | 변수·텍스트 스타일 관리, 원본 컴포넌트 섹션 관리, 신규 컴포넌트 검토·승격, 페이지 구조, 문서 | — |
| **팀원** | `개선 UI 와이어프레임` 페이지에서 화면 조립, **필요하면 새 컴포넌트 만들기(아래 규칙대로)**, 리뷰 메모 | 변수·텍스트 스타일 새로 만들기 ❌, 잠긴 원본 섹션 풀기/수정 ❌, 다른 페이지 수정 ❌ |

### 새 컴포넌트 만들어도 됨 — 단, 이 규칙으로
1. **만들기 전에 검색** — `🧩 컴포넌트 · 토큰` 페이지 🔒 섹션에 같은 게 있으면 그거 쓰기 (버튼이 3개 생기면 곤란)
2. **색은 새로 찍지 않기** — `색상` 변수에 바인딩 (`bg/surface`, `text/primary`, `primary/default` …). 그래야 나중에 SOL 모드로 한 번에 색이 입혀짐
3. **글자는 기존 텍스트 스타일** (`h2`, `body-lg/medium`, `caption/regular` …)
4. **라운드·높이는 토큰 값** — 버튼 h48 r8, 칩 h36 pill, 카드 r20/24, 좌우 여백 20 (= 기존 신한 UI 규격)
5. **오토레이아웃**으로, 이름은 한국어로 (예: `보험료 요약 카드`)
6. 만든 건 `🧩 컴포넌트 · 토큰` 페이지의 **🆕 신규 컴포넌트 (검토 대기)** 섹션에 두기 → 영준이 확인 후 원본 섹션으로 이동

## 2. 세션 시작할 때 Claude에게 붙여넣을 프롬프트 (복붙)

```
슈퍼SOL 보험 탭 리디자인 프로젝트의 Figma 작업을 도와줘. 지켜야 할 규칙:

[파일] https://www.figma.com/design/4ZvrCenVFT98F0VMIYaAp4/  (fileKey: 4ZvrCenVFT98F0VMIYaAp4)
[작업 페이지] "개선 UI 와이어프레임" 페이지에서만 작업. 내 섹션은 "👤 {내이름}" 이고, 없으면 만들어줘.
[스타일] 회색조 와이어프레임. 컴포넌트 fill은 이미 "색상" 변수에 바인딩돼 있으니 색을 새로 넣지 마.
[컴포넌트] 우선 "🧩 컴포넌트 · 토큰" 페이지의 기존 컴포넌트 인스턴스(createInstance)를 써. 정말 없을 때만 새로 만들되:
  - 만들기 전에 그 페이지에서 같은 이름/용도가 있는지 먼저 검색해서 알려줘
  - fill/stroke는 반드시 "색상" 컬렉션 변수에 setBoundVariableForPaint로 바인딩 (새 색 hex 금지)
  - 텍스트는 기존 텍스트 스타일(textStyleId) 사용, 라운드/높이는 토큰(버튼 h48 r8, 칩 h36 pill, 카드 r20/24, 여백 20)
  - 오토레이아웃, 한국어 이름, 완성되면 그 페이지의 "🆕 신규 컴포넌트 (검토 대기)" 섹션(노드 33:57)에 넣기
  - 변수와 텍스트 스타일은 절대 새로 만들지 마
  주요 컴포넌트 노드 ID: 상태바 9:3 / 헤더 13:67 / 상단 탭 행 12:74 / 하단 탭바 15:74 / 버튼 10:10 / 필터 칩 10:19 / 세그먼트 10:32 /
  리스트 아이템 16:70 / 상품 리스트 아이템 16:71 / 섹션 헤더 16:56 / 배너 카드 17:59 / 추천 상품 카드 17:81 / 섹션 카드 17:82 /
  유틸 카드 20:52 / 상품 카드 20:76 / 그리드 메뉴 아이템 20:77 / 검색 인풋 20:80 / 스탯 아이콘 21:57 / 키-값 행 21:62 /
  특징 카드 21:65 / 소개 카드 21:71 / 푸터 고지 21:85 / 하단 고정 CTA 15:75 / 아이콘 플레이스홀더 9:13 / 이미지 플레이스홀더 9:14 / chevron 9:16
  (variant set이면 children에서 "Type=…" 이름으로 골라서 createInstance)
[화면 규격] 폭 393, 세로 오토레이아웃(counterAxisSizingMode FIXED, primaryAxisSizingMode AUTO), 첫 뷰포트 852.
  새 화면은 "개선 UI 와이어프레임" 상단 템플릿 A(30:751) 또는 B(30:794)를 clone()해서 시작.
[하지 말 것] 잠긴 섹션(9:2) unlock 금지, detachInstance 금지, 다른 페이지 노드 수정 금지, figma.notify 사용 금지.
[폰트] Noto Sans KR (Inter는 한글 없음). 텍스트 만들기 전 loadFontAsync 필수.
[기록] 화면 하나 끝나면 프레임 노드 ID랑 어떤 문제(P-xx)를 어떻게 바꿨는지 한 줄 알려줘. 내가 문서에 옮길 거야.

지금 할 일: {여기에 오늘 만들 화면 설명}
```

## 3. 작업 중 팁
- Claude가 "새 컴포넌트를 만들까요?" 하면 → **"기존에 비슷한 거 있는지 먼저 찾아보고, 없으면 규칙대로 만들어서 🆕 섹션에 넣어줘"**
- Claude가 만든 결과가 이상하면 → "스크린샷 찍어서 확인해줘" (Claude가 `screenshot()`으로 자기 결과를 봄)
- 에러 나면 → 재시도 시키지 말고 "에러 원인 먼저 설명해줘"
- 한 번에 화면 하나씩. "화면 3개 만들어줘"는 잘 깨짐
