## 0. 먼저 한 번만
1. claude.ai → 설정 → 커넥터 → **Figma** 연결 (Figma 계정 로그인)
2. Figma 파일 열어서 첫 페이지 **📖 시작하기** 한 번 읽기 (5분)
3. 이 문서의 "시작 프롬프트"를 메모장에 저장해두기 — 매번 붙여넣을 것

## 1. 역할 분담 (중요)
| 누가 | 하는 것 | 안 하는 것 |
|---|---|---|
| **영준** | 변수·텍스트 스타일 관리, 원본 컴포넌트 섹션 관리, 신규 컴포넌트 검토·승격, 페이지 구조, 문서 | — |
| **팀원** | `개선 UI 와이어프레임` 페이지에서 화면 조립, **필요하면 새 컴포넌트 만들기(아래 규칙대로)**, 리뷰 메모 | 변수·텍스트 스타일 새로 만들기 ❌, 잠긴 원본 섹션 풀기/수정 ❌, 다른 페이지 수정 ❌ |

### 새 컴포넌트 만들어도 됨 — 단, 이 규칙으로
1. **만들기 전에 검색** — `🧩 컴포넌트 · 토큰` 페이지 🔒 섹션에 같은 게 있으면 그거 쓰기 (버튼이 3개 생기면 곤란)
2. **색은 새로 찍지 않기** — `색상` 변수에 바인딩 (`bg/surface`, `text/primary`, `primary/default` …). 그래야 나중에 SOL 모드로 한 번에 색이 입혀짐
3. **글자는 기존 텍스트 스타일** (`h2`, `body-lg/medium`, `caption/regular` …)
4. **라운드·높이는 토큰 값** — 버튼 h48 r8, 칩 h36 pill, 카드 r20/24, 좌우 여백 20 (= 기존 신한 UI 규격)
5. **오토레이아웃**으로, 이름은 한국어로 (예: `보험료 요약 카드`)
6. 만든 건 `🧩 컴포넌트 · 토큰` 페이지의 **🆕 신규 컴포넌트 (검토 대기)** 섹션에 두기 → 영준이 확인 후 원본 섹션으로 이동

  - 변수와 텍스트 스타일은 절대 새로 만들지 마

## 3. 작업 중 팁
